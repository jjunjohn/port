# Claude Code 지시문 — MD 포트폴리오 Figma 조립

(아래를 Claude Code 첫 메시지로 붙여 넣고, 같은 폴더의 01·02 파일을 함께 첨부)

---

패션 MD 인턴 지원용 포트폴리오를 Figma에서 조립해 줘.

## 첨부 파일
- `01_포트폴리오_페이지별원고.md` — 모든 페이지의 문구·숫자·각주 (내용의 유일한 기준)
- `02_디자인_지시문.md` — 색·글꼴·컴포넌트·레이아웃·차트 규칙

## 절대 규칙
1. 원고에 없는 숫자·경험·회사 정보를 만들지 마. 문장을 다듬는 건 되지만 의미·숫자는 바꾸지 마. 모르는 건 `[확인 필요]`로 비워 둬
2. 원고의 '반드시 지킬 표현 규칙'(리오더 표기 각주, 48.9%와 17.1%를 빼지 않기 등)을 모든 페이지에 지켜
3. 이미지는 넣지 마. 자리표시(#E3E3E3 + `[이미지: 무엇]`)만
4. 차트 막대 길이는 원고의 값으로 계산해서 넣어. 눈대중 금지
5. 강조색 #6EC6FF는 글자색으로 쓰지 마

## 작업 순서 (단계마다 멈추고 나에게 보여 줘)
0. Figma 파일 `[https://www.figma.com/design/pEzRjlOwlI1W6Z8GvCukmc/%EC%A0%9C%EB%AA%A9-%EC%97%86%EC%9D%8C?node-id=0-1&t=1rK3sJnDpsYxTKKo-1]`에 쓰기(편집)가 가능한지 먼저 확인해. 읽기만 된다면 진행하지 말고 바로 알려 줘
1. `00_스타일·컴포넌트` 페이지: 색 스타일 5개, 텍스트 스타일, 컴포넌트 7개(디자인 지시문 4절) → **여기서 멈추고 확인받기**
2. `마스터` 페이지: 공통 페이지 — 00 표지, 목차, 01 ABOUT ME → **멈추고 확인**
3. `마스터`: 02 DATA (2-1~2-7) → **멈추고 확인**
4. `마스터`: 04-C TNF, 05 RETAIL, 06 FORK(자리만), 07 O.F.F., 08, 09, 10 → **멈추고 확인**
5. `플랫폼 버전` 페이지: 공통 프레임 배치 + 2-6 샤오홍슈 박스 + 2-8 + 04-A 29CM 운영안. 섹션 번호 당기기(03 없음) → **멈추고 확인**
6. `브랜드 버전` 페이지: 공통 프레임 배치 + 03 블루브릭 진단 + 04-B 브리프·계산 페이지 → **멈추고 확인**
7. 두 버전을 PDF로 내보내기 전 점검 목록(디자인 지시문 9절) 결과를 보고해 줘

## 각 단계 보고 형식
- 만든 페이지 목록과 프레임 이름
- 원고와 다르게 처리한 곳이 있으면 이유
- `[확인 필요]`로 남긴 곳 목록
