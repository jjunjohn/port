# 디자인 지시문 (Figma 조립용, 2026-10-07)

내용은 `01_포트폴리오_페이지별원고.md`, 디자인은 이 문서를 따른다.

## 1. 형식
- Figma, 프레임 1920×1080 (16:9 가로), 최종 PDF로 내보냄
- 페이지 구성: `00_스타일·컴포넌트` / `마스터(공통 프레임)` / `플랫폼 버전` / `브랜드 버전`
  - 공통 페이지는 마스터에 한 번만 만들고, 두 버전 페이지에서는 인스턴스·복제로 배치. 버전별로 다른 페이지(02-6 박스, 02-8, 03, 04)만 따로 만든다
- 한 페이지 한 메시지. 여백 넉넉하게 (좌우 120px 이상, 상하 96px 이상 권장)
- **이미지는 이번에 넣지 않는다**: 이미지 자리는 #E3E3E3 사각형 + 가운데 `[이미지: 무엇]` 텍스트(#888)

## 2. 색 (색 스타일로 등록, 이것만 사용)
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| bg | #FFFFFF | 배경 |
| ink | #000000 | 제목·본문 |
| accent | #6EC6FF | 하이라이트 띠, 차트 강조 막대, 표지·CONTACT 블록 |
| chart-gray | #E3E3E3 | 차트 나머지 계열, 이미지 자리표시 |
| note | #888888 | 각주·출처·정의·작은 설명 |
- **accent(#6EC6FF)를 글자색으로 쓰지 않는다** (흰 배경 위에서 읽기 어려움)

## 3. 글꼴 (텍스트 스타일로 등록)
- Pretendard. Figma 목록에 없으면 Noto Sans KR로 대체 (문서 전체에 하나만)
| 스타일 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| H1 | 72~96 | ExtraBold | 표지 이름, 섹션 큰 제목 (영문 About Me·Data 등) |
| H2 | 40~48 | Bold | 페이지 헤드라인(결론 한 문장) |
| H3 | 28~32 | Bold | 소제목, 라벨 열 |
| Body | 22~24 | Regular/Light | 본문, 내용 열 |
| Num | 20~24 | Light | 번호(01. 02.), 표 숫자 |
| Caption | 14~16 | Regular | 각주·출처 (#888) |
- 숫자는 표 안에서 오른쪽 정렬

## 4. 컴포넌트 (먼저 만들고 모든 페이지에서 재사용)
1. **Highlight Text** — Figma에 형광펜 기능이 없으므로: 텍스트 + 뒤에 accent 사각형. 사각형 높이는 텍스트 높이의 아래쪽 45~55%, 좌우로 4~10px 더 길게. 텍스트 길이에 맞춰 늘어나게(오토 레이아웃)
2. **Label Row** — 왼쪽 라벨(H3) | 오른쪽 내용(Body), 라벨 열 너비 고정. 변형: 하이라이트 on/off
3. **TOC Row** — 번호(Num, 가늘게) + 제목(H1 또는 H2, Highlight Text)
4. **Page Header** — 왼쪽 위 섹션 표시(예: `02 DATA`, Caption) + 헤드라인(H2, 핵심 숫자만 Highlight)
5. **Footnote** — 페이지 하단 고정, Caption, 여러 줄 가능
6. **Case Block** — 관찰 / 판단 / 행동 / 결과 / 돌아보며 라벨이 붙은 세로 블록 (05·07용)
7. **Assumption Badge** — "가정 시나리오" 표시용 작은 박스 (#888 테두리, Caption) — 04B-4 계산 페이지

## 5. 레이아웃 시스템 (레퍼런스: 흰 바탕 + 검정 + 강조색 1개, 형광펜 하이라이트)
- 표지: 화면의 큰 부분을 accent 블록으로 채우고 그 위에 이름(H1)·MD Portfolio·한 줄 소개
- 목차: TOC Row 세로 나열, 제목에 하이라이트
- 01·08·09: Label Row 목록. 중요한 줄만 하이라이트
- 02·03·04 데이터 페이지:
  - 맨 위 Page Header(결론 한 문장), 그 아래 차트 또는 표 하나 + 짧은 설명 2~4줄, 맨 아래 Footnote
  - **하이라이트는 페이지당 최대 3곳**
- 05·07 사례 페이지: 왼쪽 이미지 자리 / 오른쪽 Case Block (이미지 없을 땐 자리표시 유지)
- 긴 목록은 다 나열하지 않고 "…외 n"으로 줄임

## 6. 차트 규칙 (Figma에 차트 기능 없음)
- **막대 길이는 원고의 실제 값으로 계산**해서 사각형 너비에 넣는다 (예: 최대 막대 너비 800px = 최댓값, 나머지는 비례). 눈대중 금지
- 또는 코드로 SVG 차트를 만들어 가져온다 (값 그대로)
- 색: 말하고 싶은 계열 하나만 accent, 나머지 chart-gray
- 모든 막대에 값 라벨, 축선 최소화, 범례는 필요할 때만
- 단위가 다른 두 숫자(48.9% 검색 비중 / 17.1% 상품 비중)는 **같은 축에 겹쳐 빼지 않는다** — 나란히 두 개 차트 또는 두 묶음으로

## 7. 표 규칙
- 가로 구분선만 (세로선 없음), 머리글은 H3 크기의 Bold
- 숫자 오른쪽 정렬, 강조할 행만 하이라이트
